### Transições

| Tipo | Regra |
| --- | --- |
| **assign** | Nível inicial L0 ou L1; L2+ exige evidência + approval |
| **promote** | +1 nível; exige `approvalId` + `evidenceHash`; L3/L4 → 403 |
| **demote** | Queda segura imediata (sem approval) |
| **takeover** | Operador autorizado redefine nível ≤ L2 com auditoria |
